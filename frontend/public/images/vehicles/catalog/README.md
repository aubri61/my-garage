# 차량 참고 이미지

등록 목록의 현대·기아 20개 차종 이미지를 로컬에 저장했습니다. 실제 소유 차량 사진이나 연식·트림 보증이 아닌 차종 참고 이미지입니다.

출처와 원본 URL, 저작권 표기는 `features/vehicle-registration/vehicle-media.json`에 차종별로 기록합니다. 현대·기아 공식 차량 페이지의 이미지를 사용하며, 공개 페이지에서 내려받았다는 사실이 재배포 라이선스를 부여하지는 않습니다. 니로 EV는 미국 공식 모델 이미지입니다.

`npm run assets:vehicles`는 파일 존재 여부를 확인합니다. 등록 드롭다운은 로컬 이미지가 준비된 차종만 표시하며 기타 직접 입력을 제공하지 않습니다. 파일이 누락되면 다음 dev/build 실행 시 등록 목록에서 제외합니다. 기존 차량 조회는 서버 데이터를 사용합니다.
