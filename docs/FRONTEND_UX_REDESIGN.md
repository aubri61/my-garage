# 프론트 UI/UX 재구성 — 2026-10-09

## 화면 구조

- 공통: 화이트 카드, 연한 회색 배경, 블루 강조. 로그인·회원가입·모드 선택·데모·등록·공유 화면의 테마 통일. 개발용 문구와 내부 상태 enum 대신 한국어 안내를 사용한다.
- `/renter`: 내 대여 요청 및 계약 → 픽업 위치 지도 → 대여 가능한 차량 목록/검색/필터 → 선택 차량 신청 패널. 종료·거절 내역은 지난 대여 내역에 접는다. 내부 대여 번호 대신 차량명, 당사자 이름, 주소, 기간, 상태를 표시한다. 접근 권한은 필요한 진행 상태에서만 안내한다.
- `/owner`: 새 대여 요청 → 내 등록 차량 → 새 차량 등록 → 보안 기능. 차량별 위치/공유 설정은 접어서 제공한다. 보안 기능에서 차량을 선택하면 기존 OTA 검증 컴포넌트를 연다.
- `/vehicles/register`: 차량 기본 정보 → 픽업 위치 → 공유 설정의 세 단계 카드. 인증서 발급 데모는 기존 접힘 영역에 유지하며 실제 등록과 분리한다.
- `/demo`: 동일한 화이트 테마, 상단 요청 보드, 한국어 차량명과 참고 이미지. 차량 데이터와 상태 전이는 체험용이며 앱 백엔드에 저장하지 않는다.

## 데이터 출처와 표시

조사 시 PostgreSQL `vehicles`에 19행, `model LIKE 'LIVE-%'` 10행, `pickup_location LIKE 'LIVE-PICKUP-%'` 5행이 있었다. 이는 `frontend/tests/e2e/sharing-live.spec.ts`와 `sharing-data-live.spec.ts`의 실제 API 등록 데이터다. 시드나 프론트 fallback이 생성한 값이 아니다. 후속 테스트에서도 각 실행의 차량/대여 기록을 만들었고 기존 DB는 초기화하지 않았다.

기존 노출 위치는 대여자 카드·신청 패널·지도 마커, 소유자 차량 카드/설정 입력, 계약 카드, SSE 알림이었다. `features/sharing/presentation.ts`가 알려진 테스트 문자열만 `차량 정보 확인 필요`/`픽업 주소 확인 필요`로 표시한다. 정상 모델과 주소는 유지하며, 다른 차량명이나 주소를 임의로 만들어 대체하지 않는다. 내부 ID는 API/DOM의 식별 용도로 유지하고 화면 본문과 알림에서는 숨긴다. 카드 검색도 사용자에게 표시되는 값으로 검색한다.

기존 API는 소유자 이름을 제공하지 않았으므로 `AvailableVehicle.ownerName`, `RentalView.ownerName/renterName`을 기존 사용자 이름에서 추가했다. URL·기존 응답 필드·인증·권한 검사·상태 전이·SSE 이벤트 형식은 유지했다. 이름과 이메일을 혼동하지 않으며 공개 목록에 번호판·이메일·사용자 엔티티를 추가하지 않는다. 별도의 닉네임 필드는 없어 현재는 계정의 표시 이름을 사용한다.

## 차량 카테고리와 사진

`features/vehicle-registration/catalog.ts`에 현대·기아 각 10개 모델을 정의했다. manufacturer/model/displayName, powerTypes, bodyType, imageKey/imageUrl, yearRange, 기존 한국어/영어 별칭을 담는다. 기본 연식 범위는 1986~2027이며 실제 모델별 출시/단종 연도 검증은 아니다.

아이오닉 5와 EV6는 기존 차종 참고 이미지를 재사용하며 실제 등록 차량 사진으로 주장하지 않는다. 나머지는 사진 준비 중 플레이스홀더로 표시한다. 새 차종 사진은 `frontend/public/images/vehicles/`에 추가하고 해당 카테고리의 imageUrl을 연결할 수 있다. 기존 DB 모델명은 변경하지 않는다.

전기차 필터는 확실히 전기차로 지정된 카테고리에만 적용한다. API는 개별 차량의 연료/트림을 저장하지 않으므로 가솔린/하이브리드 선택 차종을 특정 연료로 단정하지 않는다. 차종을 카탈로그에서 찾을 수 없으면 정보 확인 필요로 표시한다.

## 번호판과 위치 입력

번호판은 직접 입력한다. 2~3자리 숫자+한글+4자리 숫자 및 지역명+2자리 숫자+한글+4자리 숫자의 기본 검증을 제공하고 공백/하이픈을 정규화한다. 랜덤 번호를 생성하지 않는다. 차량 소유권이나 특수·외교·임시 번호판의 공식 유효성 검증은 아니다. 기존 데이터 및 백엔드 등록 계약은 유지한다.

카카오 services 라이브러리로 주소/장소 검색 결과를 최대 6개 표시한다. 입력 후 450ms 대기, 검색 중/결과 없음/실패 상태, 이전 검색 응답 취소 처리를 제공한다. 결과 선택은 주소와 좌표를 함께 채우고 지도에 반영한다. 지도 클릭은 좌표를 먼저 반영한 후 주소를 조회한다. 검색 실패나 주소 없는 지점에서는 직접 입력을 안내한다. 직접 좌표 입력은 접힌 고급 입력으로 유지한다.

기간 입력은 `RentalPeriodFields`로 분리했고 브라우저 로컬 시각을 기준으로 약 5분 후 시작·1시간 대여를 기본값으로 제공한다. API에는 기존처럼 ISO 시각을 보낸다. 별도 달력/예약 캘린더는 구현하지 않았다.

공식 검색 SDK: https://apis.map.kakao.com/web/documentation/#services_Places
